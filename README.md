A one-page front page summing up Friday 20 November 2026's world news in a single image, built to the winning pattern of the 18 November contest (newspaper front page, 35 stories across 7 regions): Cyclone Akvan's landfall in Odisha, Russia's missile strike on Kyiv's bridges, COP31 missing its deadline in Antalya, plus 10 more illustrated stories, a pinned world map, a 22-story list, a numbers strip and a DATE CHECK box naming the near-miss stories left out. Every story was verified as having happened, or first been reported, on Friday 20 November 2026. `entry.png` is the image; `draw.py` (Python 3 + Pillow) redraws it from the story list; `main.ts` copies `entry.png` to the output directory.

## Run it

```sh
node main.ts
```
