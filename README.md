A one-page front page summing up Friday 20 November 2026's world news in a single image: Cyclone Akvan's landfall in Odisha, Iran's Hormuz tanker claim, COP31 closing in Antalya, the India–New Zealand Test in Wellington, and more. `entry.png` is the image; `draw.py` (Python 3 + Pillow) redraws it from the story list; `main.ts` copies `entry.png` to the output directory.

## Run it

```sh
node main.ts
```
